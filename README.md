# Jiangphoto Visual Resume

Open `index.html` locally to preview. The three MP4 files are stored beside it and play directly without TikTok embeds.

For GitHub Pages:
1. Create a new public repository.
2. Upload `index.html` and `work-01.mp4`, `work-02.mp4`, `work-03.mp4` to the repository root.
3. In Settings → Pages, choose Deploy from a branch, `main` / root.
4. Wait for GitHub Pages to publish the site.

Note: the three videos total over 100 MB, but each individual file is below GitHub's 100 MB per-file limit.
